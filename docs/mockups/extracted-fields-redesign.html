DESIGN NOTES
  • Field order matches Evergy Billing Details: Customer → Facilities → Demand → Energy On/Off Pk → RkVA → Tax Exempt → ECA → EER → PTS → TDC → Bill Offset → Franchise Fee → Total
  • Double-wide cells only for Utility Company, Customer Name, and Service Address
  • Running total accumulates charge fields only, shown right of each charge row
  • Total row highlights green with checkmark when running total matches, or red if mismatched
  • kW quantity fields (Facilities kW, Billed kW, TDC kW) are paired with their charge on the same row
  • Non-charge kW fields (Meter Multiplier, Actual RKVA) are single-width, paired 2-per-row
  • All fields remain editable inputs (shown as static text in this mockup)
